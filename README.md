# 球迷共创城市记忆

保存球迷旗帜、口号、影像和城市打卡点之间的**权利关系**，支持公共文化活动长期留存群众创作。
核心约束：素材受欢迎不构成跳过权属的理由——收藏者、图案作者、入镜人物、展示场地方是不同的权利主体。

Node.js 纯领域模块，无外部依赖，运行 `npm test` 执行全部验收测试（16 项）。

## 权利关系分账（五条独立记录链）

| 关系 | 记录内容 | 模型入口 |
| --- | --- | --- |
| 实物保管 | 旗帜实物的保管位置、保管人、移交记录、跨场地借展协议 | `recordCustody` / `transferCustody` / `createLoan` |
| 数字文件来源 | 文件指纹、上传人、来源说明；**重复上传按指纹归并到同一来源链** | `registerItem` / `attachFile` |
| 作者声明 | 寄送人（`collector`）与图案作者（`author`）分开声明，认领可被受理或驳回 | `addClaim` / `resolveClaim` |
| 人物同意 | 入镜人物同意；未成年人必须有家长/监护人同意；可撤回 | `recordConsent` / `withdrawConsent` |
| 展示许可 | 按「用途 + 场地 + 期限」发放，作者可撤回某一种使用 | `grantLicense` / `revokeLicense` |

## 关键规则

- **权利未确认只能内部保存**：缺少已确认作者、缺少（未成年人家长）同意或认领冲突时，状态为
  `internal_only` / `contested`，公众视图中不出现（不泄露其存在），馆藏人员在内部视图可见全部资料。
- **每次引用绑定用途与期限**：体育场、街区、临展每次展示都经 `canReference` 校验
  （许可用途匹配、场地匹配、在有效期内、无冻结），成立后由 `createReference` 留痕。
- **撤回只停止新传播**：作者撤回某一用途后，该用途在途引用标记为 `stopped`，
  但引用记录、开始时间与所依据的许可号保留——既往合法展出永远可核查；其他用途许可不受影响。
- **衍生版本独立成件**：社区编辑的裁切、配音、翻译、主题故事通过 `createDerivative`
  生成独立素材（记录来源与变换方式），权属与许可需独立确认，不自动继承原件。
- **争议先冻结再保全**：`openDispute` 立即冻结原件及全部衍生版本的传播，
  并对当前权利记录做哈希快照保全；`resolveDispute` 只允许 `rights_officer` 角色作出处理决定。
- **多入口按同一状态收敛**：每次权利变化递增 `rightsVersion`。`LicenseCache`
  以「版本号 + TTL」双重失效——认领冲突、跨场地借展、许可撤回或缓存过期时，
  体育场/街区/临展三个入口的下次查询统一重算为拒绝，缓存不会吐出未授权内容。

## 角色视图

- `staffView(registry)`：馆藏人员全量视图——保管位置、声明、同意、许可、权利状态。
- `publicView(registry)`：公众视图——仅含 `public` 素材，展示作者署名、来源链与有效许可。

## 文件结构

- `src/domain.js`：登记处、权利裁定、引用校验、衍生版本、争议冻结、角色视图、许可缓存。
- `src/scenario.js`：题述场景样例（旗帜寄送人≠作者、含未成年人的合影、三场地引用、撤回、衍生、冲突、冻结、借展）。
- `test/domain.test.js`：16 项验收测试。
- `src/seed.js` / `fixtures/seed.json`：原始领域样例与稳定标识校验（基线保留）。
